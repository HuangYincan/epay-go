# 收款观察上下文

观察器记录候选证据，网关管理证据的授权归属；支付平台、商户和设备是不同身份。

## Language

**Receiver（收款账户）**：某一环境与支付平台下被登记的稳定收款账户。它不是手机、商户或一次设备绑定。
_Avoid_: 用“账户”同时指商户或设备；将receiver称为临时绑定。

**Binding（观察授权绑定）**：某个设备对一个receiver的一代观察授权。更换设备产生新代次，历史授权仍可追溯。
_Avoid_: 把key轮换当成换绑；重用旧代次。

**Channel alias（通道别名）**：网关支付通道对同一receiver的引用。不同别名不代表不同实际收款账户。
_Avoid_: 以通道ID代替真实收款账户身份。

**Device credential（设备凭据）**：允许某个设备按固定绑定范围上报证据的独立凭据。
_Avoid_: notify_key、商户API Key、管理员凭据。

**Observer evidence（观察证据）**：设备所见通知形成的不可变候选记录。它不是支付平台签发的交易凭证。
_Avoid_: 到账证明、支付流水。

**Pairing grant（配对授权）**：管理员为指定收款范围创建的短期、单次登记许可。
_Avoid_: 长期设备凭据、商户授权。
